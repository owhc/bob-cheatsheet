Agent Personas 🆕

執行流程
使用者需求› Commands› AGENTS.md› Rules› Skills› 完成
載入優先級（低 → 高）
  • ① 全域規則 ~/.bob/rules/
  • ② 工作區模式規則 .bob/rules-{mode}/
  • ③ AGENTS.md（專案根目錄）
  • ④ 工作區一般規則 .bob/rules/
⚠️ 重要：五大機制會累加 token 成本，避免在不同機制中重複相同內容，善用 Memory Import 共享配置。

03 Memory Import 記憶匯入
在 AGENTS.md 中使用 @path/to/file.md 引用外部檔案。節省 50–70% tokens。最大引用深度 5 層。
特性說明
模組化拆分大型文件
可重用跨專案共享
安全循環引用偵測
效能省 50–70% tok
推薦結構
.bob/
  ├── agents/       ← Personas 🆕
  ├── skills/
  ├── rules/
  ├── commands/
  └── memory/
      ├── core/
      └── project-context.md
Token 節省機制
為何節省避免各機制重複相同內容，透過 @path 共享模組
運作方式新對話時自動解析 @ 語法，動態載入引用檔案
引用方式@./.bob/memory/core/tools.md

06 Token 節省策略
核心策略
  • 精準任務：明確具體的描述
  • Line Range：只讀需要的行
  • 批次處理：一次完成相關任務
  • 選對工具：apply_diff > write_file
高成本警示
  • 高 讀取 >1000 行大檔案
  • 高 相同檔案重複操作
  • 中 不明確的模糊任務
  • 中 無限制全專案掃描
成本估算參考
操作類型Token 成本優化建議

OAuth 2.1 🆕
  • Bob 自動處理完整 OAuth 流程及 token 刷新
  • 只需設定 server URL，無需手動管理 token
  • Settings → MCP → Renew / Reset auth 管理狀態

  • 身份驗證：API key 或 OAuth
  • 加密傳輸：HTTPS/TLS
  • 存取控制：最小權限原則
  • 稽核記錄：記錄所有操作

11 最佳實踐 & 資源
實戰技巧
  • 從小開始：AGENTS.md + 1–2 Rules
  • 逐步擴展：需要時才加
  • 保持簡短：每檔單一主題
  • 定期審查：移除不用的配置
  • 版本控制：配置納入 Git
常見錯誤
  • 過度配置：一開始建所有機制
  • 內容重複：多處寫相同規則
  • 檔案過大：AGENTS.md > 500 行
  • 缺乏組織：Memory 沒有分類
  • 忽略成本：載入不必要內容
